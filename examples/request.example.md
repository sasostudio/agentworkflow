# 로비에 최근 전적 3판 표시

## 목표
- 로비 화면에 최근 3판의 승패가 보인다
- 전적이 없으면 "아직 전적이 없어요"가 보인다

## 구현 범위
- 로비 컴포넌트에 최근 전적 영역 추가
- 전적 데이터는 기존 전적 저장소에서 읽기만

## 범위 외
- 전적 저장 방식 변경
- 랭크·결제·인증 관련 코드

## 주의

- 새 외부 패키지 추가 금지
